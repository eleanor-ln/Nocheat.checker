# NoCheat Checker

Minecraft bite, process, file cheat checker.


### Powershell runs

```powershell
irm https://raw.githubusercontent.com/eleanor-ln/Nocheat.checker/main/nocheat-checker.ps1 | iex
```


### CMD Runs

```cmd
powershell -NoProfile -ExecutionPolicy Bypass -Command "irm https://raw.githubusercontent.com/eleanor-ln/Nocheat.checker/main/nocheat-checker.ps1 | iex"
```
